# キャラ一覧クラウド保存（Google Apps Script）

`Code.gs` は、Googleスプレッドシートを非公開の保存先として使うためのGASウェブアプリです。
GitHub Pages側にはGASの公開URLだけを置き、GoogleアカウントのメールアドレスやスプレッドシートIDは置きません。

## 初期設定

1. 保存先に使うGoogleアカウントで、新しいGoogleスプレッドシートを作成します。
2. スプレッドシートの `拡張機能` → `Apps Script` を開きます。
3. Apps Script側の `Code.gs` 全文を、このフォルダの `Code.gs` で置き換えます。
4. 関数一覧から `setupHoshimichiCloud` を選び、一度だけ実行します。
5. Googleの確認画面で、このスプレッドシートを読み書きする権限を許可します。
6. 関数一覧から `seedCurrentCharacters` を選び、一度実行します。紅焔、フィトリアット・マリアベル、カイト、カーヴェイン、シーリス・アルタイル、シェイナム、マイン・A・レッドフォックスが初期登録されます。
7. `デプロイ` → `新しいデプロイ` → `ウェブアプリ` を選びます。
8. 実行するユーザーを自分、アクセスできるユーザーを匿名を含む全員にします。
9. 発行された `/exec` で終わるURLをコピーします。`/dev` URLは使用しません。
10. `index.html` 内の次の行へURLを設定します。

```javascript
window.HOSHIMICHI_CLOUD_API_URL = "https://script.google.com/macros/s/.../exec";
```

11. GitHub Pagesを更新し、Googleへログインしていないブラウザから一覧・保存・読込を試します。

`seedCurrentCharacters` は同じ固定IDまたは同名の有効なキャラがすでにある場合は追加をスキップするため、誤って再実行しても重複登録しません。共有一覧へ保存される初期データは公開用情報だけで、KP向け秘匿設定は含めていません。

GASコードを変更した時は、既存デプロイを新しいバージョンへ更新します。新しいデプロイを毎回作る必要はありません。

## 自動作成されるシート

- `Characters`：キャラ一覧用の現在版情報と、一覧専用の軽量サムネイル
- `Revisions`：現在版を含む最新3版の記録
- `PayloadChunks`：キャラJSONを分割した本文
- `Usage`：日本時間の日付別通信回数

キャラJSONは1セルの文字数上限を避けるため、Base64へ変換して40,000文字ずつ分割します。現在版と過去2版だけを保持します。過去版へ戻す操作は古い版を直接上書きせず、その内容を使った新しいrevisionを作ります。

一覧画像はブラウザ側で最大200×300pxへ縮小され、45,000文字以下のData URLだけを`Characters`の`thumbnail_data_url`列へ保存します。元画像はGASへ送信しません。旧9列構成の`Characters`は、最初のAPI通信時に既存行を残したままサムネイル列を自動追加します。

## 公開範囲

この構成はアカウント登録のない、全利用者共通の公開キャラ一覧です。誰でも一覧の閲覧、保存、更新、論理削除を実行できます。ビルダーの確認画面は誤操作防止であり、利用者を認証するものではありません。

削除はスプレッドシートから物理削除せず、`deleted_at` を設定して一覧から隠します。ブラウザ側のローカルバックアップも削除しません。

画面右上の通信回数は、GASが受け取ったAPI処理1件ごとに、日本時間の日付別で1回加算します。Google側の残り割当量ではありません。削除操作では、削除対象を端末へ退避する読込と論理削除の合計2通信を行います。カウンター確認だけの追加通信は行いません。

## 通信上の注意

ブラウザからの保存は、CORSの事前確認を避けるため `URLSearchParams` を使った単純POSTで送信します。GASの応答は別ドメインへリダイレクトされるため、公開後に次の環境で実機確認してください。

- Windows Chrome／Edge
- Android Chrome
- iPhone Safari
- プライベートブラウズ
- Google未ログイン状態

特定環境で応答を読み取れない場合は、GASの前段にCORSを正式に制御できる中継APIを置くか、フロント側をGAS HtmlServiceへ移す必要があります。
