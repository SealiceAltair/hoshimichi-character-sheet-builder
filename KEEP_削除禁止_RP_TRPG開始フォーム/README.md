# 削除禁止：RP・TRPG開始フォーム保全一式

このフォルダは、キャラクタービルダーへ追加した「このキャラで遊ぶ」機能の原型と設計意図を残すための保全場所です。

## 取り扱い

- ユーザーが保全解除を明示するまで削除しない。
- キャラクタービルダー全体を作り直す場合も、整理対象や旧試作として削除しない。
- 画面を改修する場合は、ここにある原型と下記の必須要件を確認する。
- 候補・妄想・保留を自動的に決定へ昇格させない。

## 内容

- `original-form-preview.html`：最初に作成し、ユーザーが確認した独立版フォーム
- `INTEGRATION_NOTES.md`：キャラクタービルダーへ入れる目的と維持事項

## 現在の採用形

キャラクタービルダー本体の上部へ、次の二つのタブを置く。

```text
キャラクター作成
このキャラで遊ぶ
```

「このキャラで遊ぶ」タブは、作成中のキャラクター名、主な武器、能力、技能、設定を読み取り、その人物向けのシナリオ・RP依頼文を作る。

```text
キャラクター作成
↓
このキャラで遊ぶ
↓
遊びたい内容を選ぶ
↓
キャラ情報入りの開始メッセージをコピー
↓
AIがそのキャラ向けのシナリオまたはRPを準備
```

## 正本上の開始条件

星みちTRPGでは、生成文を送っただけで本編を開始しない。

```text
正本確認
→ シナリオ作成・選択
→ /シナリオ準備
→ 固定fixtureによる起動試験
→ READY
→ ユーザーの /シナリオ開始
→ 本編開始
```
